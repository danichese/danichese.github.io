# Specification: Portfolio Migration & AI Persona

## Overview
This track focuses on rebuilding the existing static portfolio using Next.js and Tailwind CSS, while simultaneously updating the content to reflect a transition to an "AI-Assisted Full Stack Developer."

## Requirements
- Scaffold a new Next.js project with TypeScript and Tailwind CSS.
- Port existing assets (images, PDFs) to the new structure.
- Implement a "High-Tech & Futuristic" yet "Human-Centric" UI.
- Showcase new GitHub projects (`PSP-Lab`, `Security-Service-Decomposition`) as hero items.
- Create a Markdown-based CV system that updates based on project data.
- Ensure full responsiveness (Mobile vs. Desktop optimizations).

## Technical Constraints
- Target Deployment: GitHub Pages.
- Framework: Next.js (Static Export).
- Styling: Tailwind CSS.
