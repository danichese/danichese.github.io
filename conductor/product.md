# Product Definition

## Vision
To transform the existing portfolio into a showcase for an "AI-Assisted Full Stack Developer," demonstrating how modern AI tools allow for the rapid creation of complex, full-stack solutions that go beyond traditional manual development methods.

## Target Audience
- **Primary:** Technical Recruiters and Hiring Managers looking for developers who leverage AI for efficiency and innovation.

## Key Features & Goals
1.  **AI-Native Rebranding:**
    -   Update the visual aesthetic to be modern and sleek.
    -   Shift the professional narrative from "Frontend Developer" to "AI Full Stack Developer."
    -   Highlight the transition from Knowledge/Technical Writing to Engineering, showing how AI expands the technical toolkit.

2.  **Project Showcase:**
    -   **Hero Projects:** Feature `PSP-Lab` and `Security-Service-Decomposition` at the top.
    -   **Narrative Focus:** Each project will explain *how* AI was used to solve problems and build features that would have been time-consuming or difficult with manual methods.
    -   **Tech Integration:** Explicitly mention the stack and AI tools used (Gemini, Cursor, Copilot).

3.  **CV Generation:**
    -   Create a downloadable/viewable Markdown CV.
    -   Include a dedicated "AI & Tools" section.
    -   Emphasize the pivot from Technical Writing to Full Stack Development.

## Success Metrics
-   A deployed portfolio that accurately reflects the new "AI Full Stack" persona.
-   Seamless integration of the new GitHub projects.
-   A professional CV artifact ready for job applications.
